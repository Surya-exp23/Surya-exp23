### 🧪 Debug-This (a tiny interactive corner)

Nobody else puts a bug hunt in their README. Here's one — no peeking at the answer before you try:

```cpp
#include <iostream>
int fib(int n) {
    if (n <= 1) return n;
    return fib(n - 1) + fib(n + 2); // 🐛 one wrong sign
}
int main() {
    std::cout << fib(5);
}
```

<details>
<summary>🔍 Click to reveal the fix</summary>
<br>

`fib(n + 2)` should be `fib(n - 2)` — as written, it recurses upward forever and blows the stack instead of converging to the base case.

</details>
